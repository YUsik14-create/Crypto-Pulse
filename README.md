# CryptoPulse — Профессиональный веб-терминал криптовалютной биржи

Полноценное full-stack веб-приложение для мониторинга котировок криптовалют в реальном времени и симуляции спотовой торговли в стиле Binance и CoinMarketCap.

> ⚠️ **Важное примечание:** Приложение является интерактивным симулятором для обучения и аналитики. Все балансы ($50,000 USD и 4,500,000 ₽) и сделки являются виртуальными и не требуют реальных денежных средств.

---

## 🚀 Основной функционал

1. **Реальное время котировок (WebSocket + REST Polling):**
   - Прямой стриминг тикеров с Binance WebSocket API (`wss://stream.binance.com:9443/stream?streams=...`).
   - Автоматический fallback на REST API каждые 8 секунд.
   - Анимация вспышек цены (Flash Green / Flash Red) при каждом изменении котировки.
   - Индикатор статуса соединения LIVE.

2. **Монеты и аналитика:**
   - 20+ активов: Bitcoin (BTC), Ethereum (ETH), Toncoin (TON), Notcoin (NOT), Solana (SOL), BNB, XRP, Dogecoin (DOGE), Cardano (ADA), TRON (TRX), SUI, PEPE и др.
   - Интерактивные графики TradingView-style: выбор периодов **1H**, **1D (24H)**, **1W (7D)**, **1M (30D)**, **1Y**.
   - Переключение отображения: **Японские свечи (Candlesticks)** с фитилями и гистограммой объемов или **Линейный график с градиентом**.
   - Рыночные метрики: капитализация, 24ч объем, 24ч High/Low, циркулирующее предложение, исторический максимум (ATH) и процент отката.

3. **Личный кабинет и торговый симулятор:**
   - Регистрация и авторизация (с хешированием паролей bcrypt и JWT-токенами).
   - Быстрый демо-вход в 1 клик для мгновенного ознакомления.
   - Стартовый баланс каждого нового пользователя: **$50,000 USD** и **4,500,000 ₽ RUB**.
   - Виртуальные покупки (BUY) и продажи (SELL) с мгновенным пересчетом средневзвешенной цены входа (cost basis).
   - Полноценная страница портфеля: расчет чистой стоимости (Net Worth), расчет нереализованной прибыли/убытка (PnL в валюте и %), структура распределения активов.
   - История всех операций (покупки, продажи, начисления, сброс баланса) с точными метками времени.
   - Возможность пополнить виртуальный счет (+ $10,000 / + 1,000,000 ₽) или сбросить демо-баланс до стартового.

4. **Индикаторы и сервисы:**
   - Живой индекс страха и жадности (**Crypto Fear & Greed Index**) с расшифровкой зон.
   - Мультивалютность: переключение между **USD ($)**, **EUR (€)** и **RUB (₽)** с динамическим пересчетом всех графиков, цен и портфеля.
   - Быстрый калькулятор-конвертер валют (Крипто ↔ USD ↔ EUR ↔ RUB).
   - Тёмная и светлая тема оформления.
   - Система всплывающих уведомлений (Toasts) о действиях пользователя.

---

## 🛠️ Архитектура проекта

- **Frontend:** React 19, TypeScript, Tailwind CSS v4, Lucide Icons.
- **Backend:** Node.js, Express, `server.ts` с поддержкой единого запуска dev-сервера (Vite middleware) и production static delivery.
- **Database:** Встроенное надежное хранилище данных `data/database.json` с атомарной записью, поддержкой транзакций пользователей, истории сделок и портфелей. Не требует установки внешних СУБД.
- **Безопасность:** Секретные ключи не передаются во frontend, пароли пользователей хешируются солью `bcrypt`, сессии защищены JWT.

## 📋 Инструкция по установке и запуску

### 1. Системные требования
- **Node.js** версии 18.0+ (рекомендуется Node.js 20 или 22).
- **npm** версии 9.0+.

### 2. Клонирование и установка зависимостей
```bash
# Клонируйте репозиторий или перейдите в корневую папку проекта
cd cryptopulse

# Установите зависимости
npm install
```

### 3. Настройка переменных окружения (`.env`)
Скопируйте пример конфигурационного файла:
```bash
cp .env.example .env
```

Параметры в `.env`:
```env
# Порт сервера (по умолчанию 3000)
PORT=3000

# Режим работы ('development' или 'production')
NODE_ENV="development"

# Секретный ключ для подписи JWT токенов авторизации
JWT_SECRET="your-super-secret-jwt-key"

# Дополнительно: GEMINI_API_KEY и APP_URL (при необходимости)
```

### 4. Запуск в режиме разработки (Frontend + Backend)
Приложение запускается **одной командой**:
```bash
npm run dev
```
Express-сервер поднимется на порту `3000` (`http://localhost:3000`) и автоматически подключит Vite HMR middleware для клиентской части.

### 5. Запуск базы данных
База данных инициализируется **автоматически** при первом запуске сервера в файле `data/database.json`. Она уже предзаполнена демонстрационным аккаунтом:

*(Также доступна кнопка входа в демо-аккаунт в 1 клик прямо в окне входа).*

## 📦 Production сборка и запуск

### 1. Сборка клиентского бандла
```bash
npm run build
```
Команда скомпилирует клиентские файлы в директорию `dist/`.

### 2. Запуск production сервера
```bash
npm start
```
Сервер запустится в production-режиме (`NODE_ENV=production`), отдавая оптимизированные статические файлы из папки `dist/` и обрабатывая все API-маршруты `/api/*`.

## 🐳 Развёртывание (Deployment)

### Развёртывание через Docker:
Создайте простой `Dockerfile`:
```dockerfile
FROM node:22-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
RUN npm run build
EXPOSE 3000
ENV NODE_ENV=production
CMD ["npm", "start"]
```

Сборка и запуск контейнера:
```bash
docker build -t cryptopulse .
docker run -p 3000:3000 --name cryptopulse-app cryptopulse
```

### Развёртывание на VPS (Ubuntu / Debian + PM2):
```bash
# Установка PM2 глобально
npm install -g pm2

# Сборка проекта
npm run build

# Запуск приложения через PM2
pm2 start server.ts --name "cryptopulse" --interpreter tsx

# Сохранение конфигурации PM2
pm2 save
pm2 startup
```
